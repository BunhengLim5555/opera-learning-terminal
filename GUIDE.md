# A small learning workflow

1. Run npm start. Choose /opera → Select source, or start with /learn followed by a topic.
2. Ask for an explanation, prediction or comparison. OPERA explains mechanisms and uses one useful objective.
3. Say “quiz me.” Answer one question, request hints if needed, read feedback, then say “next” when ready. “Show the answer” gives the solution without pretending you independently solved it.
4. Ask “draw this” when a map or walkthrough would clarify a relationship. The saved HTML opens in your browser when supported.
5. Say “save a note” for a focused concept note, or “save a checkpoint” to preserve your current objective, source section, evidence, pending question and next action.
6. Later use /learn with no topic or /opera → Resume. Use /review for one observed weak/due target.

The /opera home is a single list. Style and practice-interface choices each open one selection list; source selection offers files, folders, links and saved sources. There are no game menus or separate quiz/source commands.

Styles are changeable preferences, not learning-type diagnoses. Explain gives direct explanations; Socratic waits for one fair prediction; Hands-on uses small practical work; Visual uses useful diagrams; Balanced mixes concise explanation and optional application.

Written reasoning is the default for explanation and practical predictions. Optional browser activities remain available by natural request; they do not require another tutoring system or separate model call. Audio cannot establish speaking ability without qualified assessment. No mandatory diagnostics, course plans or review backlog.

Notes contain purpose, mechanism, an example, a useful contrast/limit and source. Recall answers are separated. No automatic full-session Markdown logging is performed. Pi session history remains the conversation record.

A checkpoint is a compact handoff, not an invented achievement. Submitted answers awaiting assessment take priority on resume. Earlier independent evidence is preserved when later answers need help. Skips, cancellations and technical failures do not count as wrong answers.

Existing .opera/games, .opera/game-content and Learning/Games records are inert historical archives. No game launcher or renderer remains. Do not delete those records to clean up the application.

PPTX sources include numbered slide text and speaker notes. MP4 sources support timestamped video-frame samples and available subtitles; choose a vision-capable model for frames. Ask for a specific time range. Speech requires subtitles or optional local Whisper transcription; missing audio understanding is reported explicitly. See README.md for source-format limits.
